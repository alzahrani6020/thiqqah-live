# ثقة الذهبية — الموقع الإلكتروني

الموقع الرسمي لمكتب **ثقة الذهبية للخدمات العامة وتأسيس الأعمال** في المملكة العربية السعودية.

🔗 **الرابط:** [https://thiqqah.live](https://thiqqah.live)

## عن المكتب

مكتب خدمات عامة متخصص في:
- تأسيس الشركات والمؤسسات في السعودية
- التراخيص البلدية والبناء
- متابعة الجهات الحكومية ومدن الصناعية
- إدارة الأملاك والمشاريع
- خدمات الأفراد وتأشيرات السفر

## هيكل المشروع

هذا المستودع يحتوي على نسخة **Static Export** من موقع Next.js، بالإضافة إلى أدوات داخلية لإدارة الكمبيالات مبنية على Firebase.

```
.
├── index.html                    # الصفحة الرئيسية
├── services/                     # صفحات الخدمات (عربي)
├── en/services/                  # صفحات الخدمات (إنجليزي)
├── blog/                         # المدونة
├── 404.html / 404/index.html     # صفحة الخطأ
├── assets/                       # الصور والخطوط والأيقونات
├── _next/                        # ملفات Next.js الثابتة
├── lib/                          # إعدادات Firebase + حماية الكمبيالات
├── letterhead*.html              # أدوات الكمبيالات
├── scripts/                      # سكربتات التوليد والنسخ الاحتياطي
├── DEPLOYMENT.md                 # دليل النشر والإعدادات
├── site.webmanifest              # إعدادات PWA
├── sitemap.xml                   # خريطة الموقع
└── robots.txt                    # إرشادات محركات البحث
```
